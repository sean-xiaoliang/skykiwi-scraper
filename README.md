# 天维网 租房 / 招聘 信息抓取工具

抓取 [天维网](https://bbs.skykiwi.com/)「租房中心」和「求职招聘」版块最近 N 天的帖子，按区域、价格、岗位类别、工作性质、距离等条件筛选，并导出 Excel。提供图形界面和命令行两种用法，可打包为 Windows 单文件 exe。

## 功能

- **本地缓存**：抓过的帖子存在本机，打开软件直接显示；点「刷新」只抓新帖（第二次刷新通常只需几秒）
- **抓取**：默认显示最近 10 天的帖子（在「⚙ 设置」中修改 1–60 天），并进入帖子读取结构化字段
  - 租房：周租金、出租类型、房屋类型、地址、设施、电话、微信
  - 招聘：公司、职位、工作地点、薪金、工作性质、工作时间、联系方式
- **筛选**：租房和招聘各有一个标签页，条件互不影响；修改后立即生效，不用重新抓取
  - 租房：区域（下拉多选）、出租 / 求租、周租金区间、出租类型、房屋类型
  - 招聘：岗位类别（下拉多选）、工作性质（全部 / 全职 / 兼职）、招聘 / 求职、时薪区间、职位
  - 通用：地址 / 工作地点、必须包含的关键词、排除词、排除已租 / 已招满、排除商家广告
- **距离**：设置家庭住址后，估算每条帖子与你的距离，可按距离排序或限定最大距离（租房和招聘都适用）
  - ◎ 一键定位：通过 Windows 定位服务获取当前位置
  - 也可输入街道地址、街区名或 `纬度,经度`
- **简历匹配**：在招聘页上传简历（PDF / Word / TXT），在本机分析技能方向、语言、证照、签证、工作年限，给每个岗位打匹配分
- **邮件申请**：有邮箱的招聘帖可一键打开写信窗口，主题和正文按模板自动填好；有邮件客户端就用客户端，没有就用 Gmail / Outlook.com 网页版
- **导出 Excel**：当前标签页的筛选结果，包含全部字段，带超链接、筛选器和冻结表头

## 快速开始

### 直接使用 exe

在 [Releases](../../releases) 下载 `SkykiwiScraper.exe`，双击运行，无需安装 Python。

### 从源码运行

需要 Python 3.10+。

```bash
pip install -r requirements.txt
python skykiwi_scraper.py          # 图形界面
python skykiwi_scraper.py --cli -h # 命令行帮助
```

## 图形界面

1. 选择「租房」或「招聘」标签页，点顶部的「刷新租房 / 刷新招聘」（F5）。第一次会抓取最近 10 天的全部帖子，以后只抓新帖
2. 在标签页上方设置筛选条件，修改后立即生效；数字填错时输入框会标红，该条件不生效
3. 在「家庭住址 / 距离」一栏点「◎ 一键定位当前位置」，或输入地址后点「按地址定位」；勾选「按距离排序」或填写「最大距离 km」
4. 表格只显示关键列，拖动表头边缘可调整列宽（会记住）；单击一行在下方查看全部信息（分隔条可拖动），双击或回车在浏览器打开原帖，点击表头排序
5. 点顶部的「导出 Excel」（Ctrl+E）导出当前标签页的结果
6. 招聘页：点「上传简历…」后出现「匹配」列并按匹配度排序；选中有 ✉ 的岗位，点「✉ 邮件申请选中岗位」

## 设置（⚙）

| 项目 | 说明 |
|---|---|
| 显示最近 N 天 | 默认 10 天，范围 1–60；调大后点「刷新」会补抓更早的帖子 |
| 读取帖子详情 | 关闭后刷新更快，但没有租金、薪金、地址、邮箱等信息 |
| 清空本地缓存 | 删除已缓存的帖子，下次刷新重新抓取（缓存保存最近 60 天） |
| 邮件发送方式 | 自动 / 邮件客户端 / Gmail 网页版 / Outlook.com 网页版；会显示检测到的邮件客户端 |
| 邮件主题和正文 | 可用占位符 `{职位}` `{公司}` `{标题}` `{链接}` `{简历摘要}` |
| 选中简历文件 | 邮件链接无法自动添加附件，打开写信窗口时会在资源管理器中选中简历，拖进邮件即可 |
| 恢复默认列宽 | 撤销手动调整过的列宽 |

## 简历匹配度

简历只在本机分析，不会上传。匹配度 0–100：

- 岗位类别与简历的技能方向吻合 +35
- 岗位标题、职位、正文中出现简历里的技能关键词，每个 +15（最多 45）
- 岗位要求英语 / 驾照：简历满足 +10，不满足 −10
- 求职帖（别人在找工作）不计分

支持 PDF（需可复制文字，扫描图片版读不出来）、Word `.docx`、TXT；旧版 `.doc` 请另存为 `.docx`。

**默认设置**：只显示「出租」和「招聘」帖（勾选「求租」「求职」可加上）；排除标题注明「已租」「已招满」的帖子。点「重置筛选」恢复默认。

**快捷键**：F5 抓取 · Ctrl+E 导出 · 回车 / 双击 打开帖子 · Ctrl+C 复制选中帖子的标题和链接

## 命令行

```bash
# 东区和北岸、周租 200–400 的出租房
SkykiwiScraper.exe --cli --category rent --region 东区 北岸 --sort 出租 --min-price 200 --max-price 400 -o 租房.xlsx

# 以当前位置为家，8 km 内的租房，由近到远
SkykiwiScraper.exe --cli --category rent --here --sort-distance --max-distance 8 -o 附近租房.xlsx

# 服务人员和清洁类的兼职
SkykiwiScraper.exe --cli --category job --job-type 服务人员 清洁/家政 --nature 兼职 -o 兼职.xlsx
```

exe 是窗口程序，在 cmd 中请用 `start /wait SkykiwiScraper.exe --cli ...`，让 cmd 等它运行完再显示提示符；进度和结果会输出到当前窗口。源码运行时把 `SkykiwiScraper.exe` 换成 `python skykiwi_scraper.py`。

常用参数：

| 参数 | 说明 |
|---|---|
| `--category rent\|job` | 租房 / 招聘 |
| `--days N` | 最近 N 天，默认 10 |
| `--region ...` / `--job-type ...` | 租房区域 / 岗位类别，可多个 |
| `--sort ...` | 出租、求租、招聘、求职 |
| `--min-price` / `--max-price` | 周租金或时薪区间 |
| `--nature 全职\|兼职` | 工作性质 |
| `--keyword ...` / `--exclude ...` | 必须包含 / 排除的关键词 |
| `--here` / `--home "地址"` | 家庭住址：当前位置 / 指定地址 |
| `--sort-distance` / `--max-distance KM` | 按距离排序 / 最大距离 |
| `--no-detail` | 只抓列表，不进帖子（更快，但没有租金等字段） |
| `--no-geocode` | 不联网解析地址，只用离线街区匹配 |
| `--no-cache` | 不用本地缓存，重新抓取全部帖子（默认只抓新帖） |
| `-o 文件.xlsx` | 导出文件名 |

## 距离是怎么估算的

预估距离是**直线距离**，不是驾车距离。每条帖子的位置按以下顺序确定，「定位依据」一列会写明用的是哪一种、信息来自地址、标题还是正文：

| 精度 | 依据 | 表格中的距离 | 说明 |
|---|---|---|---|
| 地址 / 街道 | 帖子写了门牌号或街道名 | `2.3` | 联网（OpenStreetMap Nominatim）解析；同名街道选与帖子上下文最近的一处，离所在分区太远的结果会丢弃 |
| 街区 | 识别出街区、地标或城市名 | `3.3`，不到 1 km 显示 `<1` | 离线匹配内置的约 250 个地名，支持中文、繁体和常见叫法（梅西、奥大、倒霉路、植物园等）；跳过"开车去 X""排除 X"这类描述 |
| 区域 | 只知道大区（东区、北岸…） | `≈5`，整行灰色 | 用大区中心估算，误差可达数公里；按距离排序时排在位置可靠的帖子后面 |

联网解析每个地址约 1 秒（遵守 OpenStreetMap 每秒 1 次的使用限制），结果缓存在 `%APPDATA%\SkykiwiScraper`，再次运行会很快。

**一键定位**需要打开 Windows 定位：设置 → 隐私和安全性 → 位置 → 打开「定位服务」和「允许桌面应用访问你的位置」。

## 隐私

- 家庭住址、坐标、简历路径只保存在本机 `%APPDATA%\SkykiwiScraper\config.json`；帖子缓存在同目录的 `posts.db`
- 简历在本机分析，不会上传；只有你点「邮件申请」时，邮件内容才会交给邮件客户端或网页邮箱
- 勾选「联网解析帖子地址」时，帖子地址、你输入的家庭住址、一键定位得到的坐标（用于反查街道名）会发送给 OpenStreetMap Nominatim；取消勾选（命令行加 `--no-geocode`）则不发送，只用离线匹配
- 抓取到的联系方式等信息仅供个人查找房源和工作使用

## 打包 exe

```bash
build.bat
```

先运行全部测试，通过后生成 `dist\SkykiwiScraper.exe`（约 20 MB）。

## 测试

```bash
python test_geo.py    # 定位：用例来自真实帖子中出现过的定位错误
python test_core.py   # 租金/薪金识别、筛选、排序、抓取容错、Excel 导出、配置、日志
python test_features.py  # 本地缓存与增量刷新、简历分析与匹配、邮件
python test_gui.py    # 布局、高 DPI、标签页、即时筛选、多选下拉、排序、列宽、设置、缓存、简历、邮件（会短暂打开窗口）
```

测试使用临时数据目录，不会读写你的配置和缓存。

## 项目结构

```
skykiwi_scraper.py   抓取、筛选、排序、导出、命令行、日志
gui.py               图形界面（标签页、多选下拉、后台任务）
geo.py               位置识别、地址解析、一键定位、距离计算、配置
store.py             本地帖子缓存（SQLite）
resume.py            简历读取、分析、岗位匹配
mail.py              邮箱提取、邮件客户端检测、写信链接
nz_places.py         内置地名坐标（来源：OpenStreetMap）
version.py           版本号
test_*.py            测试
build.bat            先测试再打包
CHANGELOG.md         版本记录
```

## 注意事项

- 只访问天维网 `robots.txt` 允许的页面（版块列表和帖子），所有请求共享限速，请勿调高频率
- 程序依赖网站当前的页面结构，网站改版后可能需要调整
- 程序出错时，详细信息写在 `%APPDATA%\SkykiwiScraper\app.log`，反馈问题时请附上这个文件
